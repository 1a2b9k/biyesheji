## 一、选题的背景与意义

### 1.1 研究背景

随着我国资本市场个人投资者规模的持续扩大，以东方财富股吧为代表的网络社区已成为散户交换观点、表达情绪的主要场所。这类平台上每天产生的文本数量巨大、更新极快，且以**短文本**为主——一条股吧标题通常只有十几个字，却浓缩了投资者对某只股票的看法与情绪。对这些文本进行自动情感分析，既能为个体投资者提供市场情绪参考，也能为监管部门观察舆情走向提供数据支持。

从技术角度看，中文财经短文本的情感分析有其特殊性。一方面，金融领域存在大量专业术语与行业黑话（如"割肉""满仓""戴帽""站岗"），通用领域的情感词典与预训练语料难以直接覆盖；另一方面，股吧文本口语化严重、语法不规范、反讽与反问频繁出现，给标注与建模都带来了困难。

近年来，以 BERT 为代表的预训练语言模型在通用领域文本分类任务上取得了显著效果，将其迁移到金融领域已成为研究热点。与此同时，传统机器学习方法（如 TF-IDF 特征结合逻辑回归）虽然结构简单，但在小规模标注数据上依然具有竞争力，且训练成本远低于深度模型。因此，**在同一份数据上系统比较两条技术路线**，并进一步分析模型的错误结构，具有明确的工程与学术价值。

### 1.2 研究意义

**理论意义。** 现有研究多以"提升准确率"为单一目标，较少追问模型究竟在什么边界上犯错。本课题在完成基线对比之后，进一步对错误结构做量化分析，试图回答"瓶颈究竟在模型能力还是在标签体系"这一问题，可为同类研究提供一种分析范式。

**实践意义。** 本课题最终交付一套可运行的情感分析系统，具备数据采集、情感标注、可视化展示的完整链路，可直接用于个股舆情监测场景，具有较强的工程实用性。

**专业契合度。** 本课题依托江西财经大学的财经学科背景，将计算机技术应用于金融信息处理，属于"财经+信息技术"的交叉方向，符合专业培养目标。

## 二、国内外研究现状

> 本节所引文献均为实际检索所得并逐条核实元数据，完整著录见文末"主要参考文献"。方括号中的编号与该节一一对应。

### 2.1 文本情感分析的通用方法

文本情感分析的研究路径大致经历了三个阶段。

**第一阶段是基于情感词典与规则的方法。** 这类方法依赖人工构建的情感词典，通过统计文本中正负情感词的极性得分来判断整体情感倾向。赵妍妍等把情感分析任务归纳为情感信息抽取、情感信息分类、情感信息检索与归纳三类，为该领域界定了任务边界[1]；陆文星等进一步总结了中文文本在分词、词典与语序上的特殊性[2]。基于词典的方法优点是无需标注数据、可解释性强；缺点是对领域迁移极为敏感，且难以处理否定、转折与反讽等复杂语言现象。

**第二阶段是基于传统机器学习的统计方法。** 这类方法将文本表示为词袋或 TF-IDF 特征向量，再交由朴素贝叶斯、支持向量机或逻辑回归等分类器判别。TF-IDF 的词项加权思想可追溯至 Sparck Jones 提出的逆文档频率概念[3]，后由 Salton 等系统总结为完整的词项加权体系[4]。在分类器一侧，Cortes 与 Vapnik 提出的支持向量机[5]被 Joachims 系统引入文本分类后，长期是文本分类的标准基线[6]。TF-IDF 通过词频与逆文档频率的乘积衡量词语对文档的区分能力，能有效抑制高频无意义词的干扰，至今仍是文本分类任务中不可或缺的强基线。

**第三阶段是基于深度学习的表示学习方法。** 从早期的卷积神经网络与循环神经网络，到以 BERT 为代表的双向 Transformer 预训练模型，文本表示能力显著提升。Devlin 等提出的 BERT 采用掩码语言建模与下一句预测两个预训练任务，在大规模无标注语料上学习通用的上下文相关表示，再通过少量标注数据微调即可迁移到下游任务[7]，已成为文本分类的主流方案。面向中文场景，Cui 等提出的全词掩码策略针对中文分词边界做了适配，进一步提升了中文预训练模型的表现[8]。

**短文本场景还面临额外的困难。** Saif 等指出推文这类极短文本存在上下文缺失、特征稀疏与噪声密集的问题[9]；Chen 等在 SemEval-2017 金融微文本与新闻情感分析任务中，把金融短文本的难点归纳为文本极短、多目标、货币表达与外部引用[10]。股吧标题与推文同属极短文本，上述困难在本文的数据上同样存在。

### 2.2 金融领域情感分析的专门研究

由于通用模型在金融文本上表现不佳，研究者开始构建金融领域的专用资源与模型。Loughran 与 McDonald 用数据证明，为其他学科开发的通用词典会在金融文本上系统性误判：哈佛词典中被判为负面的词，有近四分之三在金融语境下并不含负面含义[11]。Malo 等构建的 Financial PhraseBank 则从另一个角度指出，整句的语义倾向可能不同于其中单词先验极性之和，因此金融短文本的情感标注不能简单由词典累加得到[12]。

在预训练模型方向，Araci 于 2019 年提出的 FinBERT 是该方向的开创性工作之一[13]；Yang 等在金融语料上继续预训练 BERT，进一步说明领域自适应预训练优于纯通用预训练[14]。

中文金融情感分析方面，国内学者针对财经新闻、股吧评论、研报摘要等不同文本类型开展了大量研究。祝清麟等指出金融领域实体级情感分析缺乏足够标注语料、通用情感模型难以有效处理金融文本，并构建了百万级金融领域语料库与金融情感词典 FinLexNet[15]；李大宇等构建了包含 923 万余条股市评论的中文金融情感数据集 StockSentCN，其人工评估的 Kappa 一致性达 0.85、加权平均 F1 达 90.34%[16]。近两年，中文金融领域也出现了 FinMoE、SNFinLLM 等大模型方向的探索[17][18]。总体来看，这些工作呈现出两个特点：一是**数据来源高度集中于财经新闻**，针对股吧这类口语化短文本的研究相对较少；二是**评价指标以准确率为主**，在类别分布不均衡时容易掩盖少数类的性能缺陷。

### 2.3 投资者情绪与市场关系

另一条研究脉络关注投资者情绪与市场表现之间的关联。Antweiler 与 Frank 对 Yahoo! Finance 与 Raging Bull 上超过 150 万条帖文的研究表明，论坛帖文有助于预测市场波动率，对收益率的影响统计显著但经济上很小，且**帖文之间的分歧度与成交量上升相关**[19]。

国内针对 A 股市场的研究同样丰富。段江娇等选取东方财富网股吧个股帖子提取情绪，结合证券分析师对个股的"中性"评级，发现股票当日收益率与当日论坛情绪显著正相关、未来两日收益率与帖子数显著负相关、当日帖子数显著正向影响当日及未来两日股价波动、情绪分歧度越大未来两日交易量越大[20]。王娜等抓取东方财富网上证指数股吧实时帖文构建投资者情绪指数并检验其有效性[21]；尹海员等分别用 Bi-LSTM 与 LSTM-CNN 挖掘股吧投资者情绪，考察其对股价泡沫与股价崩盘风险的影响[22][23]。在"情感特征能否改善股价预测"这一问题上，Luan 等基于自建的 24 只 A 股、12000 条人工标注评论数据集发现，加入情感通常能改善预测，但对个股并不总是一致[24]；李梦等以华银电力为例，把 BERT 对股吧舆情的情感分类结果与行情时序数据融合后输入 LSTM，走势准确率上升 8.63%[25]。

上述研究为本课题提供了应用场景的支撑，但结论并不一致，且预测效果受情绪度量方式、时间窗口与市场状态影响较大。由于本课题聚焦文本侧的情感识别本身，不涉及金融计量建模，这部分内容仅作为系统功能的延伸方向。

### 2.4 评价方法与标注质量

在评价指标一侧，Sokolova 与 Lapalme 系统梳理了分类任务的性能度量，给出了宏平均与微平均精确率、召回率、F 值的明确定义，为不均衡场景下以宏平均 F1 为主指标提供了依据[26]。Opitz 与 Burst 进一步指出，"宏 F1"存在两种不同的计算方式，二者仅在少数情形下等价，差异可达 0.5，甚至会导致分类器排名发生变化，因此报告宏 F1 时必须写明所用公式[27]。

在类别不均衡一侧，He 与 Garcia 的综述系统整理了不均衡学习的成因与对策[28]；Buda 等通过大规模系统实验发现，类别不均衡确实有害，过采样在几乎所有场景下表现最优且不会导致过拟合，当关注正确分类总数时应做阈值调整以补偿先验差异[29]；Chawla 等提出的 SMOTE 是过采样方向的经典方法[30]。

在标注质量一侧，Cohen 提出的 Kappa 系数是量化标注者分歧的原始出处[31]；Landis 与 Koch 给出了 Kappa 值"轻微/一般/中等/高度一致"的分档标准，使一致性数值可被解读[32]；Artstein 与 Poesio 则系统比较了 Krippendorff's alpha、Scott's pi 与 Cohen's kappa 等系数，并指出加权 alpha 类系数在语料标注中可能比 kappa 类更合适[33]。这一组文献构成了本课题检验"中性"标签可靠性的方法学基础。

### 2.5 现有研究的不足

综合以上，现有研究存在以下不足，也正是本课题的切入点：

1. **对股吧短文本关注不足。** 多数中文金融情感分析研究使用财经新闻语料，而股吧文本的口语化程度、噪声水平与新闻差异很大，直接迁移效果存疑。尽管已有段江娇等[20]与 Lou[34]分别在实证与技术两条路径上使用东方财富股吧数据，但前者侧重金融计量、后者侧重交易回测，均未深入分析情感标签体系本身。
2. **评价指标单一。** 大量研究仅报告准确率，缺少宏平均 F1 与混淆矩阵，无法揭示类别间的性能差异；即便报告宏 F1，也鲜有说明所用公式[27]。
3. **忽视标签体系本身的问题。** 现有工作普遍把标注数据当作"真值"，很少检验标签语义是否存在复合性缺陷。而 Malo 等已指出整句语义倾向不等于词级极性累加[12]，Loughran 与 McDonald 也证明同一词语在不同领域下的极性会发生变化[11]，这提示"中性"这一类别的语义边界本身值得怀疑。
4. **缺少"模型能力"与"标签质量"的分离论证。** 已有研究在模型表现不佳时，往往直接归因于模型容量或数据规模，缺少通过对照实验把两类原因区分开的系统性设计。

经检索，目前尚未见到专门讨论"中性 / 无态度 / 提问"三类语义在同一个标签下相互混淆的可核验文献。这正是本课题希望填补的空白。

## 三、研究内容

本课题以东方财富股吧标题为研究对象，围绕"模型对比"与"瓶颈分析"两条主线展开，具体包括以下四个部分。

### 3.1 数据获取与质量核查

获取公开的东方财富股吧标题人工标注数据集，核查其规模、标签分布、文本长度特征、重复样本情况以及训练集与测试集的重叠情况，确保后续实验结论的可信度。

### 3.2 两条技术路线的对比实验

在同一份数据上，分别实现并训练：

- **路线一（基线）：** 中文分词（jieba）+ TF-IDF 特征 + 逻辑回归分类器
- **路线二（本文）：** 基于 `bert-base-chinese` 的微调

在三个任务切分下对比两条路线：

| 任务 | 定义 | 类别数 |
|---|---|---|
| 任务 A | 三分类（负面 / 正面 / 中性） | 3 |
| 任务 B | 二分类极性（剔除中性样本） | 2 |
| 任务 C | 中性 vs 有情感 | 2 |

评价指标包括准确率、宏平均 F1、加权 F1 与混淆矩阵，并给出多数类基线作为参照。同时记录训练耗时与显存占用，以便从"效果—成本"两个维度综合比较。

### 3.3 错误结构分析与瓶颈定位

这是本课题区别于常规对比实验的核心部分。在完成三分类实验后，进一步分析：

1. **错误流向分析。** 从混淆矩阵出发，分别按"预测类别"与"是否牵涉中性边界"两种口径归并错误，量化模型究竟在"看涨还是看跌"上犯错更多，还是在"有没有态度"上犯错更多。
2. **问句统计。** 统计各类别样本以问号结尾的比例，检验"中性"标签是否把"真的没有态度"与"只是在提问"两类样本混在了一起。
3. **句式切分实验。** 保持模型与训练数据不变，仅将测试集按句式切分为陈述句组与问句组，比较两组指标差异。
4. **剔除问句重训实验。** 从训练集中剔除问句样本后重新训练，观察指标变化，以判断问句样本究竟是噪声还是有效监督信号。

### 3.4 系统设计与实现

将训练好的模型封装为服务，构建完整的情感分析系统：

- **后端：** 基于 FastAPI 提供数据采集、存储、情感推理与统计接口
- **前端：** 基于 Vue 3 与 ECharts 实现行情 K 线、情感分布、新闻列表的可视化看板
- **数据库：** MySQL 存储股票、日线行情与新闻数据
- **算法实现：** 基线路线基于 scikit-learn 实现 TF-IDF 特征提取与线性分类器[35]；BERT 路线基于 HuggingFace Transformers 加载中文预训练权重并微调[36]
- **降级设计：** 模型文件缺失时系统自动退化为基础版，保证采集与展示功能不受影响

## 四、研究方法与技术路线

### 4.1 研究方法

1. **文献研究法。** 通过检索国内外相关文献，梳理文本情感分析的技术演进与金融领域的专门研究，明确本课题的定位。
2. **实验研究法。** 在控制变量（随机种子、超参数、数据划分固定）的前提下开展对比实验，保证结果可复现。
3. **定量分析法。** 使用准确率、宏平均 F1、混淆矩阵等指标量化模型性能，并对错误分布做统计分析。
4. **软件工程方法。** 采用分层架构与模块化设计实现系统，通过自动化测试保证质量。

### 4.2 技术路线

```
数据获取（公开标注数据集）
        │
        ├─→ 数据质量核查（分布 / 重复 / 泄漏）
        │
        ├─→ 路线一：jieba 分词 → TF-IDF → 逻辑回归
        │
        └─→ 路线二：bert-base-chinese 微调
                    │
                    ▼

                    │
                    ▼
        自动化测试 → 可视化看板
```

### 4.3 可行性分析

**数据可行性。** 所需数据集已获取并完成实测：训练集 8516 条、测试集 2130 条，合计 10646 条；标签分布为负面 29.8%、正面 28.4%、中性 41.8%，不均衡度 1.47；**重复样本 0 条、训练测试重叠 0 条**，划分干净，结论可信。

**算力可行性。** 本机配备 NVIDIA RTX 5060 显卡（sm_120 架构）与 CUDA 13.0 环境，已实测 PyTorch 可正常调用 GPU（矩阵乘法结果与 CPU 一致）。BERT 微调吞吐约 119 样本/秒，单次训练耗时 70～150 秒，显存峰值 2.03 GB（总 8 GB），算力充足。

**技术可行性。** 后端 FastAPI、前端 Vue 3 与 ECharts 均为成熟框架，开发者已具备相应实践经验；模型训练脚本已实现并跑通，三个任务的对比实验数据已产出。

**前期基础。** 目前已完成基础版系统（数据采集 + 存储 + 展示）与情感分析模块的开发，后端 203 项、前端 67 项自动化测试全部通过。三个任务切分下两条技术路线的对比实验已跑通，初步结果如下（同一份数据、固定随机种子，两条路线各自重新训练）：

| 任务 | 类别数 | TF-IDF + 逻辑回归 | BERT 微调 | 多数类基线 |
|---|---|---|---|---|
| A 三分类（负面/正面/中性） | 3 | 0.6296 | **0.7540** | 0.4089 |
| B 二分类极性（剔除中性） | 2 | 0.7546 | **0.8435** | 0.5091 |
| C 中性 vs 有情感 | 2 | 0.7352 | **0.8099** | 0.5911 |

（表中为准确率；BERT 单次训练耗时 109.3～146.0 秒，TF-IDF 为 3.3～10.9 秒。）

在此基础上，错误结构分析已取得初步发现：三分类任务的 524 个错误中，有 **385 个（73.47%）牵涉中性边界**，而负面与正面直接互错仅 139 个（26.53%），前者是后者的 2.8 倍。这提示模型的主要困难在"有没有态度"这条边界上，而非"看涨还是看跌"，为本课题第三部分的研究内容提供了直接依据。

## 五、预期成果与创新点

### 5.1 预期成果

1. 一套可运行的财经舆情情感分析系统（含源代码与部署说明）
2. 三个任务切分下两条技术路线的完整对比实验数据
3. 一份关于"中性"标签瓶颈的量化分析报告
4. 毕业论文一篇

### 5.2 创新点

1. **研究对象上**，聚焦股吧短文本这一相对少被关注的财经文本类型，而非通常使用的财经新闻。
2. **分析方法上**，不满足于报告准确率，而是从混淆矩阵出发做错误结构分解，并设计句式切分与剔除问句重训两组对照实验，把"模型能力问题"与"标签体系问题"区分开。
3. **工程实现上**，系统具备模型缺失自动降级能力，保证了在无 GPU 环境下的可用性。
